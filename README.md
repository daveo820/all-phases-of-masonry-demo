# All Phases Of Masonry: concept demo

Hand coded static concept site by LuminArch for All Phases Of Masonry (Wilmington, NC). Not an official site. `noindex`, robots Disallow.

- Live: https://all-phases-of-masonry-demo.vercel.app/
- Build: `python3 build.py` writes the HTML pages. No framework, no build step on Vercel.
- Docs: `market-research.md`, `FACTS_LOG.md`, `DESIGN_DNA.md`. Competitor screenshots in `research/`.
- Fonts: Instrument Serif and Mulish (SIL OFL), self hosted in `fonts/`.
